# MizoApps - Facebook 2012 Style 🇮🇳

> Facebook hlui 2012 ang chiah, Mizo tawng support na nen siam.

Mizo tan, Mizo tawngin, Mizo kut (Chapchar Kut, Thalfavang Kut) te nen.

**Live Demo:** https://mizoapps-fb2012.vercel.app

---

## ✨ Features - A Kim Vek

- 🔐 **Login Page** - Facebook 2012 design, Mizo tawng
- 📰 **News Feed** - Photo upload, Status, Check-in
- 👥 **Friends** - Thian list, add/remove, search
- 👨‍👩‍👧‍👦 **Groups** - Group list + Member list + Add member LIVE
- 🔔 **Notifications** - Hrilhna (Like, Comment, Friend request)
- 👤 **Profile** - Timeline, About, Friends, Photos tabs
- ✏️ **Edit Profile** - Hming, Veng, Kum, Hnathawh edit
- 🔍 **Search** - Mizo users zawngna
- 🖼️ **Photos** - Album (Chapchar Kut 2012, Thalfavang Kut etc)
- 💬 **Messages** - Chat UI, Online indicator, Unread count
- ⚙️ **Settings** - Duhsakna, Privacy, Log out
- 🎉 **Events** - Kut leh Programme
